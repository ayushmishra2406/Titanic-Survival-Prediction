# Titanic Survival Prediction using Machine Learning

This project is a part of my Machine Learning Internship at CodSoft.

The aim of this project is to build a Machine Learning model that predicts whether a passenger survived the Titanic disaster based on different features such as age, gender, passenger class, fare, and family information.

---

## Dataset

- Source: Kaggle Titanic Dataset
- Total Records: 891
- Features Used:
  - Passenger Class
  - Sex
  - Age
  - SibSp
  - Parch
  - Fare
  - Embarked

---

## Technologies Used

- Python
- Pandas

- Matplotlib
- Scikit-learn
